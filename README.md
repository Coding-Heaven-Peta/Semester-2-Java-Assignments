HEALTHFIRST PIMS - Setup Instructions

Requirements:
- Java JDK 14 or higher
- MySQL Server

Setup Steps:
1. Install MySQL if not already installed
2. Open MySQL Workbench
3. Run database.sql to create the database and tables
4. Navigate to the artifacts folder
5. Double-click tshiamopeta_pims.bat to launch the app
